# Security Policy

## Reporting Security Vulnerabilities

We take the security of this repository and the accuracy of compliance guidance seriously.

If you discover a security vulnerability in the automated testing scripts, CI workflows, or integration examples, please report it responsibly:

- **Email**: Send vulnerability details to `ruturajj@techvishwaguru.com`.
- **Response Time**: We endeavor to acknowledge reports within 48 hours and provide a fix or advisory promptly.
- **Scope**: Please do not open public GitHub issues for security vulnerabilities until a coordinated fix is released.

## Legal Accuracy Disclosures

If you discover a legal error, misstatement of the statute, or inaccurate enforcement date in the skills suite:
- Please open an issue using the [Legal Update Template](.github/ISSUE_TEMPLATE/legal_update.md) or file a pull request with official Gazette citations.
- Submissions will be cross-checked against official MeitY sources before merging.
